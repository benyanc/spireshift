## What is being compared

The same fight and preserved player supply four cells:

| Starting position | Single-change search | Coordinated search |
| --- | --- | --- |
| First eligible turn-one play menu | One changed decision, then greedy play | Up to three changed decisions, then greedy play |
| After the original greedy opening | Same single-change method | Same coordinated method |

The later root is derived from the **new original greedy reference**, not a
different sampled game or a better branch. Its prefix fixes all original actions
up to the first offered play phase in public round two or later. Its independent
reference must reproduce the exact remaining action trace, outcome and resource
view of the early reference's suffix. If that play phase never exists, the later
cells remain unavailable in the original world denominator; no replacement world
is selected. Actual public round and root remain in the sealed record.

Within each entry point, both methods receive **16 candidate slots**. Their
reference is shared. Every reference and both selected complete plans receive
separate native confirmation replays. This matches the candidate limit, **not
CPU time**, network computation or every search component. CPU and actual path
counts are measured; exhausted proposals are recorded without an invented game.
Early-versus-later comparisons test access to the original opening under this
budget, not differences between unrelated decks, worlds or stochastic players.

## Coordinated plans

The single-change arm retains the old proposal rule: alternative actions at
decisions in the reference's first three observed player rounds, followed by the
same greedy player. Candidate menus remain complete.

The new method preserves **four initial lineages**:

1. Try four initial single-change plans, with native greedy continuation.
2. For each observed plan, try two additional changes **after its first edit**.
   One changes a later meaningful choice; where available, the other changes a
   choice in a later player round. This gives eight two-change proposals.
3. Retain the better of those two children within each original lineage and try
   one further edit, giving four three-change proposals.

The total is **4 + 8 + 4 = 16** candidate slots. A losing or temporarily worse
first change is still extended. The method does not require a one-change gain
before testing a joint plan. Each extension uses the parent's **actually observed
public trace**, preserves its earlier edits and binds the changed action to an
exact current menu. It does not guess a future menu or approximate card physics.

Between the two children of one lineage, native fight win and then ending HP
rank expansion; ties use stable candidate order. All first-change lineages remain
represented, subject to available later choices. This is a small trajectory search,
not exhaustive beam/MCTS planning, a strategic value oracle or an optimal teacher.
It may miss action combinations and treats some losing intermediates as tied.

Extensions may also change observed nested combat choices. The single arm keeps
its historical combat-turn proposal rule; both resolve every actual nested menu.
Consequently this compares the practical search packages, not the isolated effect
of changing the number of actions alone. No offered action is removed from either
rollout. Proposals are limited to the first three observed rounds; the complete
remaining fight is followed through later rounds.

## Outcomes and limits

Native room rewards establish a fight win, death a loss; escape is not a win.
The preserved local criterion prefers a death-to-win rescue or a higher-HP win
with no recorded potion-multiset, deck/relic-identity, gold or maximum-HP cost
against that entry's original reference. It does not price every relic charge,
RNG/draw consequence or future strategic effect. Branches use the original fixed
hidden world, so this is explicitly privileged teacher evidence, not public-belief
search or ordinary on-policy PPO experience. Student inputs would remain public.

**Shorter verified winning lessons are counted.** The old four-choice cutoff does
not silently carry into this new comparison. Selected edit depth, actual changed
rounds, local gains, rescues, unavailable proposals, failures and candidate CPU
remain visible separately. No threshold in this collector admits a student,
promotes a model or authorizes adaptive thinking.

Each v2 native path is bounded by **192 remaining-fight actions / 12 observed player
rounds / 60 wall seconds including initialization and the saved prefix / the
unchanged 128-CPU-second attempt ceiling**. Every request uses the smaller of
20 seconds and the remaining path/session allowance. The
saved prefix bound is 512. A failed/capped path blocks the remaining paired work
at that world; other planned worlds may proceed only after verified retirement.
More than two technical failures, a prefix mismatch or confirmation difference
stops for inspection. Missing cells retain the original world denominator.

The main maximum is **576 native attempts**: eight worlds, two entries, each with
one reference, 32 candidate paths and three confirmations. Actual attempts can be
lower if a second turn or extension is absent. Branches and the two entry points
are dependent; the independent unit is the **world**, with only two fixed parents.
The report retains fitting/held-out panels and paired within-world comparisons.
It makes no population-of-initializers claim or full-game win-rate estimate.

The offline comparison's total search CPU is charged and reported separately.
It is not a claim that this planner fits a 128-second complete-run deployment
budget. Terminal full-run victory under that budget remains the project objective;
local HP comparisons and fight wins are auxiliary evidence only.
