## Implemented contract

`engine-shared-input-v1.mjs` is called by both execution paths. It requires the
current complete Ironclad/A8 snapshot, the entire legal menu and **every advertised
public read**, all bound to that exact snapshot/runtime. Missing, stale, partial,
hidden or ambiguous input stops the attempt. It never fills a missing pile with
an empty list or invents an action.

The converter orders referents by visible occurrence/ownership, rather than by
temporary handles; canonicalizes action ordering; joins a partial SDK operand to
its already-public full card/inventory facts; and rejects contradictory duplicates.
It normalizes the known potion-role alias and equivalent target-caption templates.
It also maps the pinned SDK's seven card-selection names to the shared selection
family, retaining their original purpose, ownership, card lists, bounds and controls.
Only explicitly unordered public deck/pile collections are sorted. Hand order,
per-copy costs/upgrades, card zones, status ownership, relic counters, amounts,
unknown public fields and every optional Skip/discard/leave action remain visible.
Presentation provenance is removed only after freshness/completeness validation.

The output separates the policy input from the one-frame delivery map. The model
receives no raw runtime/snapshot/action IDs; the controller uses those IDs to send
the exact current bound action. A canonical action index is never reused as an
index into a differently ordered raw menu. Tutorials/startup controls remain
explicit presentation steps, separate from learned gameplay choices.

This is one shared schema/conversion implementation, **not a claim that the two
providers already export identical information**. Source-only facts are retained
and differences reported; they are not dropped to manufacture a pass.

## Checkpoint and environment preservation

New manifest `sts2-v0.111.0-ironclad-a8-shared-v2.json` binds the actual v35 CLI,
worker v11, official connector v13, shared projection and exact frozen game.
It resolves the old v34/v35 label mismatch on separately imported copies.
The first shared manifest, manifest v9, old recipes, original files and every prior
trained final stay intact. The second shared manifest explicitly versions the
selection-name conversion; it does not rewrite the first control's lineage.

Both original numerical initializers are imported with **every weight, all Adam
first/second moments and counters exactly preserved**: 5,658 / 6,045 steps.
The new metadata/model IDs are explicit and the import receipts prove numerical
equality. Different input conversion can change behavior even with unchanged
weights; the receipts deliberately do not claim old and new behavior are identical.

Inference uses the existing production encoder/chooser: greedy combat and sampled
noncombat, with the same public navigation semantics and fixed sampling stream.
Only immutable model metadata is shared/cached. A choice uses a trial copy of the
small navigation state; public memory advances **after verified delivery**, not
when merely proposing an action. Wrong-runtime, stale, unknown or duplicate
acknowledgements cannot be retried as another choice. There are no optimizer calls.
