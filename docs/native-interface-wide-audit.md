## Consolidated repairs

- **Public shop-slot ownership:** the typed catalog already associates every
  offer with its UI slot, even while the shop is closed. The new converter creates
  canonical declarations from those exact public relations. It does not turn a
  read into an action referent, invent a purchase or accept arbitrary dangling
  IDs. Duplicate/conflicting ownership stops conversion. All 14 formerly failing
  references resolve; all 497 saved frames convert.
- **Event details at the producer:** a separately built CLI export revision v36
  uses native `EventOption` and hover models for Proceed/chosen/lethal flags,
  relic descriptions, keyword text and card previews. The game assembly and all
  game rules remain unchanged. The projection explicitly carries these fields
  into public options instead of discarding them. Missing/unknown hover variants
  stop rather than becoming an empty list.
- **Exact enablement joins:** the CLI already advertises a Boolean on the same
  option's current public referent. The converter joins that fact into its option
  properties, preserving false and rejecting conflicts. It never defaults an
  unknown flag or derives enablement from an unrelated entity.
- **Card-detail read ownership:** `surface_card` is an actual generic SDK read,
  not an unknown mechanic. Its response, descriptor and card entity must agree.
  A detail for a different card stops conversion.
- **Nullable fields:** the pinned SDK serializer may omit null nullable fields,
  including a missing removal service. Those declared exceptions are distinct
  from missing arrays or Boolean facts. No missing Boolean becomes false.

The build is explicit and reproducible: two original-baseline builds and two
repaired builds agree with their frozen pins. The measured build takes **14.42
seconds**, **522.80 MB** peak memory and **224.13 MB** of host code/build files.
These are small managed host builds, not copies of the game app. Initial development
logs, the missing old clone-cache attempt and earlier control/audit snapshots remain
preserved; the successful build reuses an existing pinned local source checkout.

The active observation lineage is shared manifest **v4**, binding CLI exports v36,
worker v11, official connector v13, the new projection and shared converter v2.
Old manifests, source patches, models, reports and entry points are unchanged.
The new imports preserve every numerical weight and Adam moment/counter exactly
(5,658 / 6,045 steps). Changed input conversion can change behavior; numerical
equality does not claim an unchanged policy distribution.
