# Compiled tutorial-entry and visible-text regressions

`native_entry_text_audit` supplies pinned assembly paths, saved text and separate
source-derived lifecycle vectors to this probe. It loads the actual reproduced
native and Connector assemblies in isolated contexts, invokes their existing
methods and returns JSON. It starts no engine, UI, profile or gameplay session.

The corpus and historical raw captures stay under ignored private artifacts.
The lifecycle vectors are diagnostics, not additional player inputs. The probe
does not turn a rejected historical receipt into a delivery or qualify a live
workflow. See [the repair guide](../../docs/native-tutorial-entry-text-repair.md)
for scope, evidence and the separate owner-run proposal.
