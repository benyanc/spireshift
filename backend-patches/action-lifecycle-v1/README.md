# Source-derived action lifecycle inventory

The tool parses the five pinned C# source snapshots with the installed compiler's
Roslyn syntax API. Source bodies and complete inventory output remain in private
ignored artifacts. The public Python audit produces dispatch/handler records,
completion contracts, support/legacy mutation sites and explicit findings.

Inventory is not effect qualification. Unknown CLI actions and new delivery
provider files reject. The separate potion proof tests bind actual native
acceptance and terminal task state without adding diagnostic state to policy
inputs. See [the audit guide](../../docs/action-lifecycle-audit-and-potion-completion.md).
